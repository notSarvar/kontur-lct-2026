# Проверка интерфейса · 28 сентября 2026

Проверены рабочий интерфейс и отдельный пульт хакатона в Chromium. Ширина экранов: 1440, 390 и 320 px. Изменяющие действия выполнялись на сервере `127.0.0.1:4330` с отдельным `DATA_DIR`; опубликованный день не использовался как тестовая фикстура.

## Найдено и исправлено

- **Добавление шага регламента на HTTP.** На публичном IP кнопка «Добавить шаг» вызывала `crypto.randomUUID is not a function`. Ошибка подтверждена на опубликованной версии без сохранения изменений. Идентификаторы новых шагов теперь создаются через `crypto.getRandomValues`, доступный и на HTTP. Проверено добавление, сохранение и повторное открытие шаблона при отсутствующем `randomUUID`.
- **Карта при быстрых переходах.** Закрытие окна во время масштабирования оставляло отложенный обработчик Leaflet, который обращался к уже удалённой карте (`_leaflet_pos`). Отключена анимация масштабирования; само масштабирование и выбор точек сохранены. Проверены быстрые переходы между картами и закрытие развёрнутой карты сразу после изменения масштаба.
- **Мобильная подпись в режиме инженера.** Добавлены пробелы между предложениями, чтобы при скрытии переноса строки слова не склеивались.

## Повторный запуск

Запускайте браузерные тесты только против отдельного сервера: они заменяют сценарии и изменяют заявки.

```sh
npm run build
PORT=4330 DATA_DIR=/tmp/kontur-ui-audit node server/index.js --production
# В другом терминале:
TEST_URL=http://127.0.0.1:4330 npx playwright test
npm test
npm run format:check
```

Для опубликованной версии используется `scripts/check-deployment.mjs`: проверяет разделы, редактор регламента на HTTP, SSE, OR-Tools, отмену предпросмотра и неизменность заявок, плана и шаблонов. Он не применяет изменения.

Проверка внешнего маршрутизатора OSRM из `live-preview.spec.js` включается отдельно; стандартный прогон использует оценку времени и подготовленную дорожную матрицу. Это проверка в Chromium, без заявления о проверке Safari и Firefox.
