# Таймер работы на объекте

При ручном начале работы сервер сохраняет метку начала, мобильный интерфейс показывает ЧЧ:ММ:СС. Перезагрузка не сбрасывает замер. Отсчёт завершается при подтверждении результата визита (полный, частичный или неуспешный).

В `state.history` добавляется запись `engineer.work.duration`: engineerId, jobId, startedAt/endedAt (Unix milliseconds), durationSeconds, normSeconds, deviationSeconds, outcome, source. source=manual означает реальные секунды, source=simulation — время демонстрационного дня. История хранит каждый завершённый визит, включая повторные попытки. В события инженера добавляется длительность и норматив.

Автоматические визиты считаются по времени симуляции. Старый уже начатый визит без серверной метки учитывается как симуляционный: его фактическое начало задним числом не придумывается. Экспорт входных данных JSON не является экспортом журнала замеров.

Таймер измеряет работу от нажатия «Начать работу» до подтверждения завершения: дорога и ожидание клиентского окна не включены. Это длительность визита, а не учёт пауз или активных действий инженера.

Аватар диспетчера открывает демонстрационный профиль с ролью, участком и описанием возможностей. Авторизация и изменение персональных данных не добавлены.
