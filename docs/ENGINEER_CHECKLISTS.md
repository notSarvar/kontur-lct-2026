# Чек-листы инженера и симуляция дня

По умолчанию включено **автозаполнение**: комплект на смену, условия применения SOP и все шаги регламента отмечены. Продвижение времени в пульте продолжает автоматически выполнять визиты; демонстрация не требует ручного заполнения. Это относится и к сохранённому дню без настройки `autoChecklists`. Новый случайный сценарий также включает автозаполнение.

На вкладке «Инженер → Мой день» доступны:

- Комплект на смену из копий SOP назначенных работ: материалы суммируются по визитам (включая явно указанный резерв), одинаковые инструменты собираются один раз. Условные позиции остаются с исходными уточнениями; для работ без SOP показывается предупреждение.
- Ближайшая работа, порядок дня, выезд, маршрут, контакт клиента и раннее прибытие.
- Чек-лист условий и шагов SOP на объекте; отметки синхронизируются с карточкой диспетчера.
- Результат визита с подтверждением. Частичное выполнение и невозможность выполнить требуют комментария и создают обращение в поддержку. Номер телефона в синтетических заявках отсутствует, поэтому звонок обозначен как демонстрация.

## Экран выезда

Карта инженера показывает только текущую заявку и подход к ней. Будущие визиты остаются в порядке дня. Если дорожная геометрия дана только для всего маршрута, на мини-карте используется пунктирная схема к текущему адресу, без линий к следующим объектам.

В карточке текущего выезда указан демонстрационный телефон `+7 ххх хх хх` и кнопка **«Скопировать»**. Копирование поддерживает HTTP-стенд и показывает результат. Под карточкой — **«Позвонить»** с заглушкой **«Звонок выполняется»**; реальный звонок не совершается. Нижняя кнопка **«Открыть в картах»** открывает в новой вкладке координаты текущего адреса. Копирование, заглушка звонка и открытие карты не меняют статус заявки.

## Ручной показ

Кнопка **«Пройти вручную»** отключает автозаполнение для всего дня, очищает комплект и отметки незавершённых заявок. Завершённые работы сохраняются. После этого:

1. Отметьте материалы и инструменты. Сбор комплекта сохраняется на сервере и переживает перезагрузку. Новые назначения или изменения перечня материалов требуют повторной проверки затронутых позиций.
2. Нажмите «Выехать на объект», затем «Я на месте». Раннее прибытие не разрешает начало раньше клиентского окна.
3. Продвиньте время при необходимости и начните работу. Ручной визит остаётся в текущем этапе до действия инженера.
4. Подтвердите условия SOP, отметьте шаги и выберите результат. Полное завершение без готового SOP сервер отклоняет. Диагностический SOP сам по себе не закрывает аварию.
5. Кнопка **«Автозаполнение»** возвращает готовые чек-листы и автоматическое выполнение по времени для продолжения презентации.

Без отдельного действия инженера симуляция в ручном режиме может начать подготовленные визиты по расписанию, но не закрывает работу с незаполненным SOP. Автозаполнение относится только к демонстрационной симуляции и не является подтверждением фактически выполненных операций.

## Проверки

`tests/engineer-workflow.test.js` проверяет автоматическое выполнение дня, ручные ограничения, количества и резерв, сохранение отметок, конфликт ревизий, новые материалы и обращение по частичному результату. `tests/browser/engineer-checklists.spec.js` проверяет оба режима, перезагрузку, переходы, мобильную ширину и синхронизацию двух клиентов.

Работать с отдельным `DATA_DIR` и тестовым портом. Изменения в `~/kontur` сами по себе не обновляют публичный выпуск.
