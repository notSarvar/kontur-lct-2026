Числа на слайде взяты из `docs/benchmark.json`: три отдельных синтетических участка, одинаковый состав инженеров для сравниваемых алгоритмов, 100 итераций ALNS. Скриншоты сняты с рабочего интерфейса на Югоцентре при стандартных 60 итерациях, поэтому расстояние может отличаться от benchmark. Наборы назначенных заявок различаются; процент экономии расстояния не заявляется. Назначение в плане не означает фактическое выполнение визита.

Проверки перед публикацией: 31 тест модели, 8 браузерных сценариев, сборка и форматирование пройдены. Опциональный тест внешнего поставщика карт пропущен; карты для скриншотов загружены отдельно. Время поездок оценочное, штат синтетический, глобальный оптимум не гарантирован.

## Воспроизведение

Создайте отдельный экземпляр приложения: съёмка перезагружает его рабочий день.

```sh
DATA_DIR=/tmp/kontur-report PORT=4319 npm run dev
```

В другом терминале, из корня репозитория:

```sh
npx playwright install chromium
REPORT_URL=http://127.0.0.1:4319 node scripts/capture-report.mjs
node scripts/build-report.mjs
```

Если браузеры установлены в нестандартный каталог, задайте `PLAYWRIGHT_BROWSERS_PATH`. Для карт нужен доступ к OpenStreetMap. `report.html` можно открыть локально вместе с изображениями. `capture.json` фиксирует дату съёмки и метрики интерфейса; отчёт содержит только синтетические данные.
